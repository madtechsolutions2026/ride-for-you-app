STEP 1: ONBOARDING & 2FA OTP AUTHENTICATION
--------------------------------------------------------------------------------
• User Action: 
  Madhu opens the Ride For You mobile app and enters his phone number (+91 7095682464).

• System Behavior:
  1. Mobile app calls: POST /auth/request-otp
  2. Backend creates an OTP challenge in PostgreSQL and sends SMS (or uses master OTP 123456 in dev mode).

• Verification:
  1. Madhu enters the 6-digit OTP.
  2. Mobile calls: POST /auth/verify-otp
  3. Backend returns a JWT access token (Bearer <token>) and refresh token.
  4. The mobile app securely stores it in tokenStore (Expo SecureStore).


--------------------------------------------------------------------------------
STEP 2: PROFILE & KYC DOCUMENT VERIFICATION
--------------------------------------------------------------------------------
• User Action: 
  Madhu navigates to Profile ➔ KYC Verification.

• Document Upload:
  Madhu captures/uploads Aadhaar Front & Back, Live Selfie, and Address/Rental Proof.

• Storage Pipeline:
  1. App requests presigned upload URLs from: POST /kyc/presign-upload
  2. Documents are encrypted and uploaded directly to Cloudflare R2 private bucket (ride-for-you-kyc-bucket).
  3. App calls: POST /kyc/submit to mark KYC as SUBMITTED in PostgreSQL.


--------------------------------------------------------------------------------
STEP 3: ENTERPRISE ADMIN REVIEW & APPROVAL
--------------------------------------------------------------------------------
• Admin Action: 
  Operations executive logs into the Admin Portal (https://ride-for-you-app.onrender.com/admin/).

• Review Queue:
  1. Admin opens the "KYC Approvals" tab in the sidebar.
  2. Madhu's submission appears under the "Pending Review" queue.
  3. Admin inspects the presigned high-resolution documents in the secure viewer modal.

• 1-Click Approval:
  1. Admin clicks "Approve & Grant High-Speed Access ✓".
  2. Backend updates user.kycStatus = 'APPROVED' and clears Redis cache.
  3. Madhu's mobile app instantly reflects verified status.
